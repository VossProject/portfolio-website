CST 363

Introduction to Database Systems

Course Description

Covers database use and design, mostly focused on relational databases. Students design schemas, write SQL, interact with databases through code, and handle admin tasks. It also gets into the algorithms behind query evaluation and transaction processing, and introduces newer technologies like NoSQL and Hadoop.
