CST 383

Introduction to Data Science

Course Description

Students learn to visualize data, spot trends, and make predictions using data analysis and machine learning techniques. The course walks through the full data science workflow: getting and cleaning data, applying ML methods, and presenting results. By the end, you should be comfortable using modern statistical programming tools on real projects.
