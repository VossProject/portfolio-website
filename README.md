# Portfolio Website

ILP (Individual Learning Plan) portfolio for the B.S. Computer Science program at California State University, Monterey Bay.

**Live site:** [portfolio-website-d6n.pages.dev](https://portfolio-website-d6n.pages.dev/)

## About

A static portfolio site that tracks coursework, projects, and goals throughout the CS Online program at CSUMB. Each course has its own page with a description and space for the final project, updated as courses are completed.

## Built With

- HTML, CSS, vanilla JavaScript
- Hosted on Cloudflare Pages

## Structure

```
index.html          Homepage (bio, program outcomes, goals, course grid)
css/styles.css      Stylesheet
js/main.js          Nav toggle and dropdown
images/             CSUMB logo, profile photo
courses/            Individual pages for each of the 15 program courses
```
